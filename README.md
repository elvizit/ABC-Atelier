# ABC Atelier

Static business card website for Academy Bespoke Costumes.

## Local preview

Open `index.html` in a browser. Keep the images, contact card, and PDF documents in the same project folder so the gallery, links, and achievement previews continue to work.

## GitHub Pages

The site entry point is `index.html` in the repository root. To publish it, open **Settings → Pages** in the GitHub repository and choose **Deploy from a branch**, branch `main`, folder `/ (root)`, then save.
